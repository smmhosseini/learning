# لیست کارها (To-Do App)

اولین پروژه من با HTML، CSS و JavaScript خالص.

## قابلیتها

- افزودن کار جدید
- علامتزدن کارهای انجامشده
- حذف کار
- ذخیرهسازی دائمی با localStorage
